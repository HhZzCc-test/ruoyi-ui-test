# 菜单导航 - 测试用例

> 页面：主布局侧边栏
> 说明：若依登录后主布局，验证侧边栏菜单展示与路由跳转
> 模块：系统监控

## TC-NAV-001

| 项目 | 内容 |
|------|------|
| 用例ID | TC-NAV-001 |
| 用例标题 | 登录后侧边栏展示核心菜单 |
| 优先级 | P0 |
| 前置条件 | 已登录 |
| 测试类型 | 功能测试 |

**测试步骤：**
| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 登录成功 | 进入 `/index` |
| 2 | 查看侧边栏 | 展示系统管理、系统监控等菜单 |

**断言清单：**
- [ ] 侧边栏菜单数量 ≥ 3
- [ ] 包含"系统管理"、"系统监控"
