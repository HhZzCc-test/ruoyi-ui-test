# 系统管理-用户管理 - 测试用例

> 页面：`/system/user`
> 说明：若依系统管理-用户管理页，支持新增 / 查询 / 重置等操作（表单基于 el-dialog）
> 模块：系统管理

## TC-USER-001

| 项目 | 内容 |
|------|------|
| 用例ID | TC-USER-001 |
| 用例标题 | 新增用户成功并可查询到 |
| 优先级 | P0 |
| 前置条件 | 已登录并进入用户管理页 |
| 测试类型 | 功能测试 |

**测试数据：** 昵称/账号 = `aitest_{时间戳}`，密码 = `Test@123`

**测试步骤：**
| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 点击【新增】 | 弹出新增弹窗 |
| 2 | 填写昵称、账号、密码 | 输入成功 |
| 3 | 点击【确定】 | 提示"新增成功" |
| 4 | 用账号搜索该用户 | 列表展示该用户 |

**断言清单：**
- [ ] 点击新增弹出弹窗，标题含"新增"
- [ ] 提交后提示成功
- [ ] 回查可搜索到该用户
