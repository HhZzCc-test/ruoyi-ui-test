# 登录功能 - 测试用例

> 页面：`/login`
> 说明：若依后台登录页，支持账号密码 + 验证码登录；验证码答案由框架直连 Redis 自动读取
> 模块：认证

## TC-LOGIN-001

| 项目 | 内容 |
|------|------|
| 用例ID | TC-LOGIN-001 |
| 用例标题 | 正确账号密码登录成功 |
| 优先级 | P0 |
| 前置条件 | 若依前后端已启动；Redis 可访问 |
| 测试类型 | 功能测试 |

**测试数据：** `admin` / `admin123` / 验证码（Redis 自动读取）

**测试步骤：**
| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 打开 `/login` | 展示账号/密码/验证码输入框 |
| 2 | 输入正确账号密码 | 输入成功 |
| 3 | 自动填入验证码并点击登录 | 跳转至 `/index` |
| 4 | 查看侧边栏 | 展示系统菜单 |

**断言清单：**
- [ ] URL 包含 `/index`
- [ ] 侧边栏存在菜单
